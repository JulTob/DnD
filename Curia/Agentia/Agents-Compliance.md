# 🧷 Agents-Compliance — Binding Every Tool to the Canon

> **Purpose:** Make every agent and tool treat the Curia as the authoritative project guide.

## Purpose
Coordination must **not depend on which AI assists Julio.** Any tool today, another tool tomorrow, a human next year — all of them obey the same Canon and Decrees. This charter binds every agent framework to the Curia.

## The binding rule
1. **The Curia Canon is authoritative.** Any agent-specific configuration, prompt, rule file, or tool instruction is **downstream** of `Canon/` and `Agora/Decrees/`.
2. **On conflict, the Canon wins.** If a rule file contradicts the Canon, the rule file is wrong → mint a Questa to fix it. Never "resolve" a conflict by bending the Canon.
3. **New tools must onboard through the Vademecum.** Before acting, a new assistant reads `Curia/Vademecum.md`, then `Canon/`, then this file.

## Keeping them in sync
- The Canon is the **source**; tool-specific instructions are optional local projections.
- When a Decree changes the Canon, any tool-specific instructions must be refreshed to match before they are trusted.
- **Agents may not silently edit the Canon to match a rule.** The arrow points one way: Canon → rules.

## For a brand-new assistant (onboarding checklist)
- [ ] Read `Curia/Vademecum.md`.
- [ ] Read all of `Curia/Canon/`.
- [ ] Skim `Agora/Decrees/` for settled law.
- [ ] Understand: propose, don't push; Julio decides; everything through a Questa.
- [ ] Only then, begin work.
