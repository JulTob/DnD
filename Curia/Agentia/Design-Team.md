# 🎨 Design-Team — Forgers of Original Content

> **Purpose:** Design original, legally clean content variations that preserve useful mechanics.

## Charge
Propose **original rule and content variations** that fit an Open-D&D project: mechanically satisfying, legally clean, and strong enough that a user could still run their favorite setting on top of them.

## When the Design-Team works
- When the **Scout** reports a rule the project might adopt but cannot copy in its published expression.
- When the **Legal-Reviewer** rules ⚠️ ("needs original re-expression") or ⛔ ("do not include") and an original equivalent is wanted.
- When Julio or the Agora asks for new content (a new subclass line, item family, condition, background).

## Principles of good Open-D&D design
1. **Mechanic, not manuscript.** Borrow how a thing *works*; invent how it is *named and told.*
2. **Original expression; precise rule labels.** Do not copy protected prose, art, characters, settings, distinctive fictional lore, logos, or source-identifying product terms. Generic words and ordinary rule labels do not need to be renamed merely because a source uses them. When a source term is genuinely protected or tied to closed setting identity, the Design-Team supplies original name, flavor, and text.
3. **Setting-agnostic strength.** Design so the engine can *run* Faerûn / Exandria / Middle-earth / Tatooine for a user without shipping those worlds. Hooks, not lore-locks.
4. **Fits the domain model.** New content must slot into TagKit the same way existing content does (see `Canon/TagKit-Doctrine.md`). If it can't, that's a `tagkit` Questa.
5. **Multiple options, with tradeoffs.** The team proposes 2–3 variations, not one — so the Agora and Julio have a real choice.

## Workflow
1. Take the Scout/Legal input.
2. Draft **2–3 original variations**, each with: name, flavor, mechanics, and how it maps to the model.
3. Send to **Legal-Reviewer** for an IP pass.
4. Send to **Technical-Team** for balance & engineering review.
5. Bring the vetted options to the **Agora** as a Dialog; Vox reports; Julio decrees.

## Output shape (per proposal)
> **Working name:** <original>
> **Inspired by (not copied):** <the mechanic/idea>
> **Flavor:** <our own short lore>
> **Mechanics:** <how it works>
> **Model fit:** <which Atlas/Tag it slots into>
> **Tradeoffs:** <power/complexity/theme>
