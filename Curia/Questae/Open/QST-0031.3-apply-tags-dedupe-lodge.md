## 🔍 Diagnosis (what & where)
The remaining hundreds of `Spell(...)` call sites (outside the now-retired `SPELL_DATA_2024`, per QST-0031.2) are the per-class-list duplicates: the same spell rebuilt independently in every class's spell list — 463 call sites for 237 unique names found during the QST-0026-lineage description-filling pass, and that count only covers the ones missing a definition; the true duplicate count (including ones that already had text) is higher.

## 🎯 Desired outcome
Every spell exists **once** in the Lodge's registry, carrying the Class-list Tags (QST-0031.1) for every class/subclass that can learn it. Wherever code today walks "the Wizard spell list" or similar, it instead **filters the one registry by Tag** (`[s for s in ALL_SPELLS if WizardList in s.tags]` or TagKit's own query idiom — consult the Guide). No spell is constructed more than once.

## 🧭 Notes for the Agora / implementer
- **Home for the list assignments (Julio's proposal, 2026-07-15, leaning agreed):** the acts of list membership — "Fireball is on the Wizard list", hundreds of such records — get their **own file**, recommended `AtlasMagia/Ledger_of_Spell_Lists.py` per Canon's `Ledger_of_X` = "lists, records, enumerations" (precedent: `Ledger_of_Weapons`, `Ledger_of_Legendary_Actions`; a ledger of entitlements fits "who may learn what"). It imports spells from the Lodge and applies `Spell_List` Tags (deriving `Tradition` via `SpellsKit.TRADITION_OF_LIST` in the same pass). **School Tags do NOT go there** — school is intrinsic to a spell, so it's applied where the spell is declared (or derived mechanically from each spell's `school` field at the Lodge's end). Net layering: SpellsKit = semantics · Lodge = spell definitions · Ledger = list membership · Grimoire_of_Spellcasters sheds its 645-line `SPELL_LISTS` dict and queries Tags.
- **Evidence from QST-0031.1's survey (2026-07-15):** (a) The Lodge holds **22 distinct raw school strings** — the 8 canonical plus trailing-space variants plus `D`/`DC`/`DG` suffixes that are Wildemount **dunamancy** remnants (Graviturgy `DG`: Magnify Gravity, Gravity Fissure; Chronurgy `DC`: Temporal Shunt, Reality Break, Time Ravage…). Normalization here must strip whitespace + suffix before consulting `SpellsKit.SCHOOLS`; whether dunamancy deserves its own marker Tag is Julio's call — don't silently discard the information. (b) **`SPELL_LISTS` has no `"Paladin"` key** while `Paladin.prepare_spells` does `SPELL_LISTS.get("Paladin", {})` (`Grimoire_of_Spellcasters.py:2151`) — the Paladin's random spell pool is always empty today. `SpellsKit.Paladin_List` already exists; this migration is where the gap gets filled with real list assignments. (c) `Map_of_Magic.py`'s shadow `class Spell` (~line 37) is vestigial dead code — never instantiated; retire it during this pass or hand it to QST-0017's orphan sweep.
- This is the highest-volume, highest-risk sidequest in the tree — it touches every class/subclass spell list in the file. Sequence last among the data-shape sidequests (.1 → .2 → .3), and consider doing it in reviewable chunks per class rather than one sweep.
- Watch for **divergence between duplicates** while merging (e.g. the `Cause Fear`/`Pass Without Trace`-style near-duplicates already found to have slightly different capitalization or fields across copies) — each divergence is a small judgment call about which copy is canonical, not a mechanical merge.
- QST-0031.4 (tests) should land a "every class-list reference resolves to exactly one registry entry" check as part of verifying this sidequest, not after.
