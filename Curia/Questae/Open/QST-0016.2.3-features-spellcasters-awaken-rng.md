## 🔍 Diagnosis (what & where)
Feature picks and spell-known / sample / shuffle paths still import module or `app.random` while running during Character awaken. Seed reproducibility breaks as soon as those layers fire.

## 🧾 Evidence
`Grimoire_of_Features/__init__.py` and `Grimoire_of_Spellcasters.py` call `random.choice` / `sample` / `shuffle` (and occasional `random.seed(caster.character.seed)`).

## 🎯 Desired outcome
Any awaken-time entropy in Features and Spellcasters draws from the owning Character’s `dices` / `Dice`. Call sites receive `char` (or `caster` with a clear path to `char.dices`), never a bare module RNG.

## 🧭 Notes for the Agora / implementer
Do not redesign Known Spells TOP modeling here (see QST-0016.7). This quest only swaps the entropy source on the existing OOP/interim paths.
