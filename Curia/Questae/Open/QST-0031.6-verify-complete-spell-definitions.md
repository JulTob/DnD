## 🔍 Diagnosis (what & where)
Across two prior passes, 234 previously-undefined `Spell(...)` names in `Lodge_of_Spells.py` were filled in from official 2024/legacy rules text (sourced from the 5etools GitHub data repo — `spells-xphb.json` plus every other sourcebook file it carries: XGE, TCE, FTD, AI, EGW, SCC, and more). **1 remains undone**: `Freedom of the Winds (HB)` — homebrew, so no published source exists to pull from. (`Widogast's Transmogrification (HB)`, the other homebrew spell in this bucket, was removed outright at Julio's call — he may reintroduce it later, but for now it's gone from the Lodge entirely, not just missing text.)

That fill-in work used one detection heuristic (an AST scan for `Spell(...)` calls with no `definition` argument or an empty one). It has **not** been independently re-verified, and it never checked:
- Whether any filled-in `definition` is malformed (stray unclosed HTML tags, leftover 5etools `{@tag}` markup that slipped past the converter, a table that rendered oddly).
- Whether the original 139-entry `SPELL_DATA_2024` dict's definitions (never touched by this work) are themselves complete and well-formed.
- Whether near-duplicate `Spell(...)` copies of the same name (the QST-0031.3 dedupe target) have **diverged** definitions that disagree with each other.

## 🎯 Desired outcome
Every `Spell` in the Lodge — both the dict and every constructor call — has a real, correctly-formatted `definition`, with no exceptions except `Freedom of the Winds (HB)`, which gets **original text written for it** (clearly not claimed as official rules) rather than staying blank. A repeatable verification (ideally landing as part of QST-0031.4's test suite, not just a one-time manual pass) that would catch this class of gap again if it recurs.

## 🧭 Notes for the Agora / implementer
- This sits naturally **before or alongside** QST-0031.2/.3 (the dict-retirement and Lodge-dedupe work) — verifying data quality before migrating it is cheaper than migrating first and discovering rot after.
- For `Freedom of the Winds (HB)`: write text in the same voice/format as the surrounding entries, and flag it unambiguously as homebrew in the Resolution when this Quest closes (not silently indistinguishable from SRD text). If Julio reintroduces `Widogast's Transmogrification (HB)` later, it re-enters the Lodge as a fresh addition, not as "still owed" from this Quest.
- Worth deciding whether "verified" becomes a standing test (QST-0031.4) rather than a one-off check, given how easily 463 silent gaps accumulated the first time with nobody noticing until this was chased down by hand.
