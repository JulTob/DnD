## 🔍 Diagnosis (what & where)

`AtlasEpica/Map_of_Titles.py` is **9,595 lines** in one module. It holds several independent word-generators sharing a file only by history:

| Function | Line |
|---|---|
| `custom_cases` | 8 |
| `Title` | 20 |
| `Descriptor` | 59 |
| `Rank` | 3,411 |
| `Place` | 7,215 |
| `Element` | 7,302 |
| `Artifact` | 7,370 |
| `Master` | 7,414 |
| `Origin` | 7,508 |

`Descriptor` alone spans ~3,350 lines of word lists. Julio's note: the file "grew massive too early in the project," and he had already begun splitting it.

This blocks reuse. The Secret Order generator (QST-0048) needs `Descriptor` + a noun to compose *"The Order of the Silent Key"*, but importing it today drags in nine thousand lines of unrelated vocabulary, and there is no seam at which to ask for "an ominous adjective" specifically.

## 🧾 Evidence

- 9,595 lines, one module, nine unrelated public functions.
- Word lists are inline literals interleaved with the functions that consume them, so no other Atlas can borrow a list without importing the module whole.
- Collision checks during background de-coupling repeatedly surfaced `Map_of_Titles.py` as the only hit for candidate names (Herald, Augur, Renegade, Marshal, Mutant), confirming it is the project's de-facto word hoard — a role it should hold deliberately rather than accidentally.

## 🎯 Desired outcome

An **`AtlasVocabularium`** (name to confirm) package where each generator owns a module and the word lists are data separate from the functions that compose them:

```
AtlasVocabularium/
├── Descriptors.py   adjectives, by mood/register
├── Ranks.py
├── Places.py
├── Elements.py
├── Artifacts.py
├── Masters.py
├── Origins.py
└── Titles.py        composes the above into a Title
```

Solved looks like: another Atlas can ask for *one ominous adjective* or *one artifact noun* without importing the title composer, and `Title()` still returns exactly what it returns today.

## 🧭 Notes for the Agora / implementer

- **Behaviour must not change.** This is a move, not a redesign: same words, same composition, same output for the same seed. Snapshot outputs before and after.
- Word lists must stay **data** (module-level tuples), so a future TOP layer can Tag them by mood or register without another move.
- Randomness on the Character path must route through `char.Pick` (QST-0016.2). Any module-level `random` encountered during the move should be recorded, **not** silently rewired — that is its own questa.
- Confirm the package name against Canon before creating it; the Atlas naming collision questa (QST-0005) is precedent for getting this right once.
- Do **not** widen into rewriting the vocabulary itself. Splitting is the whole job.
