## 🔍 Diagnosis (what & where)
Before moving scripts out of `shiny_app.py`, the presentation domain needs a home and a single source of truth for loader rune symbols — currently duplicated across `LOADER_SCRIPT` (L868–869), `base.html` (`solSymbols`, `planetSymbols`), and formerly `loaderMagic.js` (deleted).

## 🧾 Evidence
- `SOL_SYMBOLS` / `PLANET_SYMBOLS` in `LOADER_SCRIPT` — small curated sets.
- `base.html` L114–162 — much larger overlapping pools for the Flask loader.
- No `AtlasVenustas/` package exists yet.

## 🎯 Desired outcome
Create the package skeleton with **no runtime behavior change**:

```
AtlasVenustas/
├── __init__.py
└── Lodge_of_Symbols.py
```

`Lodge_of_Symbols.py` exports at minimum:
- `SOL_SYMBOLS: tuple[str, ...]` — curated sun/center runes (start from Shiny `LOADER_SCRIPT` set; may absorb unique Flask symbols later)
- `PLANET_SYMBOLS: tuple[str, ...]` — curated orbit runes
- `random_sol() -> str` and `random_planet() -> str` helpers (optional, thin)
- `if __name__ == "__main__":` self-test: pools non-empty, no duplicates within each pool, sample draw works

`shiny_app.py` is **not** rewired yet — this slice only adds the package.

> Workshop Consul (Artificer): Tuple constants, not mutable lists. Self-test at the foot per Canon.
> Julio: Some symbols have been changed as emoji instead of unicode in some users' phones. We should avoid symbols that may be translated by the text parser as emojis. 
> Julio: We should expand symbols too, using unicode as an easy to use and expand standard that we can trust users will experience as novel for many cases. An option would be to use a function as a selector, if we use the url building options, we can directly parse selected elements from there. We can, therefor, create multiple lists personalized for each background class or species. The list can build up as conditions are selected, as in the lists of names or titles. A symple but effective architecture. We can map some alphabets to species (runic to dwarves, tibethan to Dragons or dragonborn...) and some symbols to classes (mathematical symbols to wizards, flowers to druids...). This symbol lodge may be useful for other utilities, as it is already happening at some other points.
