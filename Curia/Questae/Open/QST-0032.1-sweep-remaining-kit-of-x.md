## 🔍 Diagnosis (what & where)
`Canon/Conventions.md` was respecified (QST-0032) with new/changed prefixes: `Charts_of_X`, a broadened `Compass_of_X`, `Tools_of_X`, and `XKit`. QST-0032 only renamed the four `Kit_of_X` files in `AtlasVenustas` — the obvious, directly-relevant case. Known remaining `Kit_of_X` files, **not yet reviewed**:

- `AtlasWorldBuild/AtlasOfMapmaking/Kit_of_HandDrawing.py`
- `AtlasWorldBuild/AtlasOfMapmaking/Kit_of_ScalableVectorGraphics.py`
- `AtlasWorldBuild/AtlasOfMapmaking/Kit_of_WaveFunctionCollapse.py`

These may or may not fit `Tools_of_X`'s "Context interfaces" sense as cleanly as the Venustas ones did — `Wave Function Collapse` in particular is a recognized algorithm name in procedural-generation circles, which may argue for `Charts_of_X` ("algorithms, functions, processes, actuators") instead of `Tools_of_X`. This wasn't decided during QST-0032 and shouldn't be guessed at without a Council pass through the World-Build domain (a package this session never worked in).

This Quest also stands for the **general** sweep the respecified Conventions imply: any other file across the repo that no longer fits its prefix's (updated) description is fair game to flag here, not just these three.

## 🎯 Desired outcome
Every file in the repo's name matches what `Canon/Conventions.md` now says that prefix means. Where a rename is right, it happens with all import sites updated and the app verified afterward (same bar as QST-0032). Where a file is ambiguous between two prefixes (e.g. `Kit_of_WaveFunctionCollapse` between `Tools_of_X` and `Charts_of_X`), that call goes to the Agora, not to whoever's doing the mechanical rename.

## 🧭 Notes for the Agora / implementer
- Low priority and no urgency — this is upkeep, not a bug. Fine to batch with other AtlasWorldBuild work rather than done standalone.
- Ranger's seat (ecosystem/tooling) is worth routing to specifically for the WaveFunctionCollapse question — that's exactly the kind of "does renaming this cost us searchability against the well-known algorithm name" tradeoff the Ranger seat exists for.
