## 🔍 Diagnosis (what & where)

`AtlasActorLudi/Grimoire_of_AbilityScores.py`, line 42:

```python
def __init__(AS, STR=10, DEX=10, CON=10, INT=10, WIS=10, CHA=10):
```

No `character` parameter. But callers pass one — `FeaturesKit._completed_skill_ledger` (~line 1739) builds its fixture with `AbilityScores(STR=10, …, character=char)`, and three self-tests go through it.

The restored file carries an **older, narrower signature** than the tree around it expects. This is not damage to the callers; it is a signature that travelled backwards in time.

## 🧾 Evidence

```
TypeError: AbilityScores.__init__() got an unexpected keyword argument 'character'

```

Three pre-existing FeaturesKit self-tests fail through that one helper, so `python -m AtlasLusoris.FeaturesKit` cannot go green while it stands. Character generation itself is unaffected: the live path does not use this constructor form.

`_completed_skill_ledger` predates the 2026-08-29 feat work — it is not part of QST-0050's restoration and was not modified by it.
