## 🔍 Diagnosis (what & where)

`AtlasMagia/Map_of_Magic.py` already groups spells thematically, but as **plain dicts keyed by loose strings** — `"Celestial"`, `"Undead"`, `"Traveler"`, `"Plant"`, `"Guardian Kong"` — mixing species, creature types, roles, and flavours in one namespace. Lines run to hundreds of columns with duplicated entries inside a single list.

Nothing can ask a spell what it *is*. The relation only exists as membership in an ad-hoc list, so a caller cannot request "primal spells about death" without knowing which string key someone chose years ago.

The Secret Order generator (QST-0048) needs exactly that query: **Theme → spell pool**.

## 🧾 Evidence

From `Map_of_Magic.py`:

```
"Traveler":  [BorrowedKnowledge, Augury, FindTraps, LocateAnimalsPlants]
"Celestial": [LesserRestoration, SpiritualWeapon, Aid, DetectThoughts, Augury, Aid, ...]
```

`Aid` appears twice in one list. Keys mix a role (Traveler), a creature type (Celestial), and a named individual (Guardian Kong). Julio's own note: the file "grew massive too early in the project."

## 🎯 Desired outcome

Spells carry membership as Tags on **four independent axes**, so a caller can ask for a pool by any of them, or any combination, and a spell may honestly belong to several values on every axis:

1. **Tradition** — the D&D One classification: **Arcane**, **Divine**, **Primal**. Coarse, and directly reusable as an Order axis.
2. **Domain** — open-ended and mythic: Home, the Forge, the Hunt, Death, Justice, Passage, Shadow, Memory, Debt…
3. **Guild spell list** — which classes may learn it (Wizard, Cleric, Druid, Bard, …). Today this lives in `AtlasMagia/Ledger_of_Spell_Lists.py` as name strings; as a Tag it becomes queryable and serves subclass features that grant "a spell from the X list".
4. **School of magic** — Abjuration, Conjuration, Divination, Enchantment, Evocation, Illusion, Necromancy, Transmutation. Needed by any feature keyed to a school (Wizard subclasses, Magic Initiate variants, items).

Axes are **independent**: an Order of Death may be Arcane, Divine, or Primal for entirely different reasons, and nothing about its domain should constrain its tradition.

Legacy string-keyed lists either derive from the Tags or are retired.

## 🧭 Notes for the Agora / implementer

- The three-tradition split is the **D&D One playtest** classification (Arcane / Divine / Primal), not a 2024 core rule. Treat it as a project axis, and say so in the docstring so no one mistakes it for RAW.
- A spell belonging to several domains is normal and desirable — do not force a single-domain taxonomy.
- Retiring `Map_of_Magic.py` wholesale is **out of scope**; this questa only needs the theme relation to become queryable. Coordinate with QST-0031.1 before moving spell *storage*.
- Deduplicate lists as encountered, but do not silently change which spells a species or class receives — that is a rules change, not a refactor.
