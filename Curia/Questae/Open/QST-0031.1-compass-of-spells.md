## 🔍 Diagnosis (what & where)
`Lodge_of_Spells.py` has no shared vocabulary for what a spell *is* along its natural axes — school, which class/subclass lists include it, and casting tradition — beyond a raw string field (`school`) and physical placement in one of many hand-copied per-class lists. There is nothing a spell *belongs to*; there's only where it happens to be written.

## 🎯 Desired outcome
A new canonical-types module, using **real TagKit** (`from TagKit import Tag, Imprint`, the pinned upstream — not a local reimplementation), defining:
- A **School** Tag family (Abjuration, Conjuration, Divination, …).
- A **Class list** Tag family — one Tag per class/subclass that can grant a spell (a spell can carry several).
- A **Tradition** Tag family — Arcane / Divine / Primal (Julio: "sé que es UA pero me gustó mucho la idea" — the One D&D playtest's tradition grouping, adopted here deliberately as a project choice, not because it's core-legal).

All three Tag families carry an **`Expectation`** contract restricting them to `Spell` targets only (TagKit Doctrine rule 5) — not a hand-written `assert isinstance(target, Spell)`.

## 🧭 Notes for the Agora / implementer
- **Naming:** see QST-0031's own notes — recommend `Compass_of_Spells` per `Canon/Conventions.md`'s existing `Compass_of_X` prefix (canonical types/categories), rather than `SpellsKit`. Confirm before minting the file.
- This module defines the *vocabulary* only — applying these Tags to every actual spell is QST-0031.3, and does not need to happen in the same pass.
- Check whether TagKit's `Expectation` API wants the restriction declared on the Tag class itself or asserted per-application; consult the upstream GitHub Guide (not memory) before writing this.
