## 🔍 Diagnosis (what & where)
`Lodge_of_Spells.py` has no shared vocabulary for what a spell *is* along its natural axes — school, which class/subclass lists include it, and casting tradition — beyond a raw string field (`school`) and physical placement in one of many hand-copied per-class lists. There is nothing a spell *belongs to*; there's only where it happens to be written.

## 🎯 Desired outcome
A new canonical-types module, using **real TagKit** (the pinned upstream — not a local reimplementation), defining:
- A **School** Tag family (Abjuration, Conjuration, Divination, …).
- A **Class list** Tag family — one Tag per class/subclass that can grant a spell (a spell can carry several).
- A **Tradition** Tag family — Arcane / Divine / Primal (Julio: "sé que es UA pero me gustó mucho la idea" — the One D&D playtest's tradition grouping, adopted here deliberately as a project choice, not because it's core-legal).

All three Tag families carry a **`@Pre` (Precondition)** contract restricting them to `Spell` targets only — not a hand-written `assert isinstance(target, Spell)`. *(Correction found by doing what this Quest ordered — consulting the pinned source: the Doctrine's `Expectation`/`Condition`/`Exclusion`/`Final`/`Sealed` vocabulary does not exist in TagKit v0.1.0. The real primitives are `@Pre`/`@Precondition`, `@Post`/`@Postcondition`, and the `Contract` namespace; a failing Pre raises `TagPreconditionError` and rolls the whole application back atomically. The Doctrine drift is minted separately as QST-0036.)*

## 🔨 Steps taken (2026-07-15 — under Julio's review)
1. **Consulted the pinned TagKit source first** (`.venv/.../TagKit/TagKit.py`, v0.1.0), per this Quest's own order — twice over: a direct read plus an independent survey agent. Yield: the real contract vocabulary (`@Pre`, not `Expectation` — see Desired outcome), the atomicity guarantee (failing contracts roll back class, dict, state, and Fields), the two membership semantics (`in` = is-now; `isinstance` = has-ever-been), the two target requirements (weakref support + attribute assignment; the Lodge's `Spell` satisfies both), and one sharp edge: **bare methods on a Tag body become Actions** contributed to agents, so Tag bodies stay minimal.
2. **Minted `AtlasMagia/SpellsKit.py`** owning: the `Spell` class (moved verbatim from the Lodge), `Spell_Tag` root (`@Pre Spell_Only` — only `Spell` targets), `School` family (8 canonical, exclusive via `@Pre Single_School` — a second school is rejected with rollback), `Tradition` family (Arcane/Divine/Primal, UA, non-exclusive), `Spell_List` family (Bard, Cleric, Druid, **Paladin**, Ranger, Sorcerer, Warlock, Wizard, Eldritch Knight, Arcane Trickster — keyed to match `SPELL_LISTS` for `.3`'s migration), plus `SCHOOLS`/`TRADITIONS`/`SPELL_LISTS_TAGS`/`TRADITION_OF_LIST` lookup tables.
3. **The Lodge cedes the class**: `Lodge_of_Spells.py` now imports `Spell` from SpellsKit (plain and loud, in the existing try/raise block) and its `class Spell` body is gone — first step toward "Lodge = data registry only" (`.3` finishes it). Star-import consumers are unaffected (nobody imported `Spell` by name; the import re-exports it).
4. **Verified**: SpellsKit self-test (7 assertions: tagging, root-climbing membership, multi-axis composition, Field iteration as registry, string probes, non-Spell rejection, second-school rejection with rollback held) — passed. Lodge syntax + import, `Lodge.Spell is SpellsKit.Spell`, registry instances typed correctly, `shiny_app` imports, and a Cleric NPC + Wizard PC generated and rendered end to end — all passed.

5. **Second wave (2026-07-15, Julio's design review folded in):** (a) three new intrinsic Tag families — `Spell_Level` (Cantrip + Levels 1–9, exclusive via `Single_Level`), `Concentration`, `Ritual` — auto-applied by `Spell.__init__` through public `Assign_*` helpers; each Tag's `@Record` **returns** the value, which TagKit materializes as a plain instance attribute (verified: `Firebolt.level` is an `int` in the instance `__dict__` — data, not method). (b) `ritual` is now a real `__init__` parameter (it never existed — Julio's call); the Lodge's 30 legacy "R"-marked `casting_time` strings were normalized to clean values + explicit `ritual=True` (zero R-marks remain), and renderers show "Ritual" properly. (c) `__format__` dispatch (`f"{spell:html}"`, `f"{spell:md}"`, plain default) with public method aliases (`html`/`as_html`, `md`/`markdown`/`as_md`) and module-level function aliases; the Grimoire's 15 raw-object card sites moved to `{spell:html}` so PC spellbooks keep their cards. (d) Subclass list Tags evicted per Julio: each subclass mints its own in its own file, inheriting the class list it draws from (self-test demonstrates the pattern). (e) `ABSTRACT` markers dropped (Julio: Tags ARE the abstraction mechanism). (f) Dunamancy stays out for now — `Assign_School` strips D/DC/DG and keeps the original on `spell.school_raw`. Live registries after Lodge import (0.33s): 48 Cantrips, 77 Level-3, 107 Evocation, 250 Concentration, 20 Ritual, 541 leveled+schooled.

Collateral findings, routed to their homes: 22 raw school strings in the Lodge (8 canonical + whitespace variants + `D`/`DC`/`DG` suffixes that are **Wildemount dunamancy** remnants — Graviturgy/Chronurgy on Magnify Gravity, Temporal Shunt, Reality Break, etc.) and the **Paladin gap** (`SPELL_LISTS` has no "Paladin" key, so `Paladin.prepare_spells`' random pool is always empty) → both recorded in QST-0031.3. The Doctrine drift → QST-0036. `Map_of_Magic.py`'s own `class Spell` (line ~37) is confirmed vestigial dead code — never instantiated; a `.3`/orphan-sweep candidate.
