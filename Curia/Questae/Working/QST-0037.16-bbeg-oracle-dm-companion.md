## 🔍 Diagnosis (what & where)
Epica drifted into a CYOA machine (choice path, Theme crystallize on exits, Charts loop). That is not the product. The DM needs an **inspiration oracle** keyed to one villain — beautiful scene cards when ideas run dry — not a plot graph.

**First carve (2026-07-16):** Grimoire + **Map_of_Scenes** + DM Companion UI reshaped to BBEG Oracle. Charts CYOA import retired. Area ≠ Lair. Theme Tags kept as a soft seam only.

**Stories alignment:** `Charts_of_Myth_Collapse` holds shared If/Choice/resolve/render (from Map_of_Stories). Stories moved to AtlasEpica; ActorLudi keeps a shim. Scenes collapse Area/Lair/beats through those actuators. `Map_of_Prose_Adventure` is a shim → `Map_of_Scenes`.

## 🧾 Evidence
- Julio (2026-07-16): BBEG Oracle; one card per Generate; no party object; Theme soft later; Area ≠ Lair; always mint scene NPCs with links.
- Success test: run the session from cards after ideas run out; each card must feel like it belongs *here* with *this* BBEG.
- Pattern to imitate: `Map_of_Titles` — host + Tags + RNG open/close a Lodge (not WorldBuild grid WFC).

## 🎯 Desired outcome
**BBEG Oracle** in the DM Companion:

1. **DM character (BBEG)** — NPC generator; regenerate; import from NPC URL. Tags like Druid / Dragon / Criminal gate place and beats (Titles-style).
2. **On set** — collapse and show **Area** (biome/general place: `Urban`, `Forest`, `Dungeon` = underground complex à la *Tragones y Mazmorras*) and **Lair** (specific seat: wizard tower, cult temple, vampire castle). Regen/import re-locks the frame.
3. **Generate** — one inspiration card: narrative presentation only (no DCs, no win/lose rails, no forced finale). Mix unknown upfront: plot pressure from the BBEG, or incidental faces. Soft hooks only (“If a Paladin is among you…”) from Tags — **no party object**.
4. **Always** mint named faces as real NPCs with sheet links; prose uses real elements; Tags sharpen beats.
5. **Theme Tags** — soft / later; structure must stay TOP-scalable.
6. **Retire** choice-exit CYOA and shareable choice-path URLs from this product. Grimoire + Prose Map fully refactorable.
